# 🎂 Happy Birthday Shagun — Interactive Birthday Celebration Experience

**Heartwarming. Animated. Personalized.**

> **Happy Birthday Shagun** is a handcrafted, heartfelt interactive web greeting crafted with romantic typography, floating particle animations, music playback, interactive envelope unboxing, and confetti celebrations.

---

## ✨ Features

- 💌 **Interactive Letter / Gift Box**: Tap to unbox personal wishes and warm messages.
- 🕯️ **Interactive Birthday Cake**: Digital candle blowing and cake-cutting animation.
- 🎊 **Confetti Cannon Particle Engine**: High-energy particle celebration using HTML5 Canvas.
- 🎵 **Background Celebration Music**: Ambient audio player to accompany the birthday greeting.
- 💖 **Floating Hearts & Sparkles**: Continuous CSS keyframe floaters creating a magical ambiance.
- 📱 **Mobile & Desktop Optimized**: Responsive layout looking graceful on all screen sizes.

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5
- **Styling**: Vanilla CSS3, Keyframe Animations, Pastel & Warm Glow Themes
- **Typography**: Google Fonts (*Cormorant Garamond*, *Playfair Display*, *Dancing Script*)
- **Scripting**: Vanilla JavaScript (Interactive triggers, confetti particles, audio controls)
